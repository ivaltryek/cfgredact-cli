# Security policy

## Reporting a vulnerability

Do not report vulnerabilities or real secrets in public issues. Contact the maintainer at
meet.vasani86@gmail.com with a description, affected version, and reproduction using synthetic data.
Do not send actual credentials. The maintainer can discuss disclosure and remediation with you.

## Scope

Redaction is best effort, not a guarantee that all sensitive data is hidden. See the README for
known limitations. Use a supported release or the current main branch when reporting a vulnerability.
